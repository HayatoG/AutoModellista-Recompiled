# Memória do projeto (exportada do ai-memory)

Cópia das páginas do ai-memory (projeto `decompmodellista`, workspace `default`) que guiam o trabalho entre sessões,
exportada em 25/10/2026 para que uma sessão em outra máquina (Windows, Linux) continue de onde paramos. É um retrato
do momento da exportação: o que mudar depois precisa ser exportado de novo. Comece por `../RETOMAR_WINDOWS.md`.

| Arquivo | Página original | Conteúdo |
| --- | --- | --- |
| `status.md` | `notes/auto-modellista-port-status.md` | marcos, commits, números, lições |
| `em_andamento.md` | `notes/auto-modellista-em-andamento.md` | onde paramos e o que vem a seguir |
| `roteiros.md` | `notes/auto-modellista-roteiros.md` | regra dos roteiros (estudo e vídeo), tokens e tempo |
| `ferramentas_re.md` | `notes/auto-modellista-ferramentas-re.md` | Ghidra e REA (no Mac) |
| `launcher.md` | `decisions/auto-modellista-launcher.md` | escolha do launcher (estilo B) |

Regras que valem sempre (do usuário): responder em português com acentos; usar Opus, Sonnet e Haiku conforme o caso,
**nunca o Fable**; perguntar o limite de uso semanal antes de etapas grandes; manter os roteiros (`CLAUDE.md`).
Caminhos `/Volumes/AMRecomp/...` são do Mac; no Windows, o equivalente fica onde o repositório e os builds estiverem.
